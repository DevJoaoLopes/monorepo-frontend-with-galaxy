# home

Host React app that orchestrates federated remotes.

- Loads the `list-products` remote at runtime through module federation.
- Presents a simple marketing layout describing the architecture.
- Built with Vite + React + TypeScript.

## Useful scripts
- `pnpm dev` runs the host locally.
- `pnpm build` produces the production bundle.
- `pnpm preview` serves the built output.
